# 第一编 技术分析与趋势流派

<a id="method-001"></a>
## 卡片 001 | 趋势流派（维克多 1-2-3 法则与 2B 假突破）

- 核心论断：严格趋势线不得穿透区间内任何一根 K 线；趋势反转需满足三步（①突破趋势线 → ②回踩不再创新高/低 → ③跌破/突破前拐点），而 2B 法则（盘中突破前高后迅速跌回前高下方）是最锋利的阶段性见顶预警信号。
- 逻辑链条：极值连线界定趋势斜率 → 突破趋势线意味着动能降速 → 2B 假突破揭示上方买盘枯竭与多头陷阱。
- 适用条件：日线与 60 分钟级别流动性充足的主流趋势标的（A股/美股通用）。
- 失效信号：极窄幅震荡横盘期内信号噪声偏多，需配合成交量放大确认。
- 历史案例：主流科技龙头主升浪末端多次在创新高次日放量长上影回落形成 2B 见顶结构。
- 可信度：0.85（经典通用技术基准）
- 复盘记录 2026-11-23：核心趋势股站回下降压制线，右侧转强结构清晰，适合作为攻防触发器。
- 来源：《专业投机原理》经典公开理论提炼

<a id="method-002"></a>
## 卡片 002 | 波动风控（海龟 ATR 2N 追踪止损与以损定仓）

- 核心论断：以过去 14–20 日真实波幅均值 ATR(N) 的 2 倍（2N）作为趋势仓硬止损边界，并用单笔最大风险预算（如账户总资金 1.5%）除以每股止损空间来反推建仓股数。
- 逻辑链条：高波动标的自然缩仓、低波动标的适度配仓 → 保证每笔交易承担同等风险单位（1R） → 避免被单只高波票打穿净值。
- 适用条件：中短期波段与趋势成长池建仓。
- 失效信号：突发一字跌停流动性枯竭时存在滑点跳空风险，需叠加仓位上限钳制。
- 可信度：0.85（经典风控基准）
- 复盘记录 2026-11-21：已接入工作台「R 倍数仓位计算器」自动计算整手股数。
- 来源：《海龟交易法则》经典公开理论

<a id="method-003"></a>
## 卡片 003 | 量价结构（威科夫放量滞涨与派发识别）

- 核心论断：高位出现成交量较 5 日均量放大 ≥1.8 倍但实体涨幅停滞或伴随长上影线（≥3.5%），属于典型的「努力无结果（Effort vs Result）」主力派发特征。
- 逻辑链条：高位巨量意味着筹码剧烈换手 → 买盘竭尽而价格无法推进 → 隐性供给压倒需求。
- 适用条件：经历 ≥20% 波段拉升后的主升浪加速段。
- 失效信号：低位底部放量长上影（仙人指路/试盘）不适用本条见顶规则。
- 可信度：0.80（活跃检验）
- 复盘记录 2026-11-22：高位量价背离预警命中率稳定。
- 来源：威科夫量价经典公开理论

<a id="method-004"></a>
## 卡片 004 | 动能结构（MACD 顶背驰与均线极性转换）

- 核心论断：股价创 20 日新高而 MACD 红柱面积或 DIF 峰值明显走低，属于趋势动能衰竭的顶背驰信号；一旦有效跌破 MA20 生命线，原支撑即极性转换为上方强阻力。
- 逻辑链条：价格惯性新高 + 动能衰减 → 反抽不过前高即形成右侧卖点 → 跌破生命线执行防守减仓。
- 适用条件：波段趋势股与指数日线级别。
- 失效信号：主升加速初期可能出现“钝化后再加速”，需结合 MA5 乖离与量能二次确认。
- 可信度：0.78（活跃检验）
- 来源：经典技术分析公开理论

<a id="method-005"></a>
## 卡片 005 | 筹码结构（Volume Profile 筹码峰 POC 与多流派共振带）

- 核心论断：过去 60 日成交量分布最密集的价格带（POC，Point of Control）代表市场平均持仓成本与最大套牢/支撑中枢；当筹码峰 POC 与均线、前高颈线、斐波那契回撤位在 ±1.35% 内重合时，形成高置信度「强共振支撑/压力位」。
- 逻辑链条：多流派交易者在同一价位触发一致挂单 → 流动性集中放大 → 突破或失守均具强延续性。
- 适用条件：A股、美股流动性良好的核心成交标的。
- 失效信号：财报或重大政策跳空缺口可直接越过筹码密集区。
- 可信度：0.82（活跃检验）
- 来源：订单流与筹码分布公开理论

# 第二编 A 股情绪周期与跨市场联动

<a id="method-006"></a>
## 卡片 006 | 短线纪律（MA5 正乖离 >8% 严禁追高红线）

- 核心论断：主流趋势标的现价偏离 5 日均线正乖离超过 8% 时，短期获利盘过于丰厚，严禁盘中情绪化追买，仅允许持仓者逢高分批兑现或等待回踩 5 日/10 日线消化乖离。
- 逻辑链条：乖离率极端扩张 → 均值回归引力急剧上升 → 追高买在短期情绪溢价最高点导致赔率倒挂。
- 适用条件：A 股趋势核心与弹性科技成长股。
- 失效信号：连板妖股纯筹码博弈阶段波动率远超趋势股，应归入独立短线小仓池管理。
- 可信度：0.85（核心纪律卡）
- 复盘记录 2026-11-23：多次避免在加速高开段追高吃面，归因统计显著降低 FOMO 成本。
- 来源：公开交易纪律总结

<a id="method-007"></a>
## 卡片 007 | 市场情绪（10 态情绪节点周期与高潮兑现纪律）

- 核心论断：全市场红盘率 ≥80% 或涨停炸板率 ≥35% 且最高连板触及高位敏感区时，市场进入「一致高潮 / 高潮降温」节点，应强制切换为「逢高兑现、禁追新仓」；当红盘率 ≤22% 且跌停扩散进入「冰点 / 连续冰点」时，反而不应恐慌割肉，应紧盯先于大盘企稳的主线核心等待「冰点回暖」窗口。
- 逻辑链条：一致高潮次日缺乏增量接力盘 → 冰点出清后筹码杀无可杀 → 情绪周期决定当日仓位上限与攻防通道。
- 适用条件：A 股全市场择时与仓位上限管理。
- 失效信号：重大宏观政策突发转向可跳过常规冰点直接放量反转。
- 可信度：0.86（核心择时卡）
- 复盘记录 2026-11-23：已接入工作台「跨日 10 态市场情绪状态机」每日自动追踪。
- 来源：A 股短线情绪周期公开框架

<a id="method-008"></a>
## 卡片 008 | 跨市场映射（海外科技利好高开兑现与中美剪刀差观察）

- 核心论断：当美股核心龙头（如 NVDA / SOX 半导体 / 光通信链）隔夜大涨催化 A 股映射板块大幅高开时，须先检验 A 股对应板块短期涨幅与筹码拥挤度——若前期已充分提前透支，隔夜利好往往成为资金借高开兑现的卖点；反之若出现「美股跌而 A 股核心放量抗跌/脱钩走强」，则是极强的独立主线信号。
- 逻辑链条：预期前置交易 → 利好落地即兑现 → 唯有脱钩强承接或业绩硬上修才能走出二波。
- 适用条件：A 股 AI 算力、光模块、PCB、半导体设备等与纳指/费城半导体强映射赛道。
- 失效信号：产业发生超预期订单翻倍式跃迁时，高开后仍可能连续逼空。
- 可信度：0.88（跨市场核心卡）
- 复盘记录 2026-11-23：通过跨市场盯盘看板实时监控中美映射剪刀差。
- 来源：中美科技股跨市场联动公开观察

# 第三编 基本面定价与行为金融防错

<a id="method-009"></a>
## 卡片 009 | 业绩定价（预期差决定股价，而非绝对增速）

- 核心论断：股价涨跌取决于「实际兑现相对市场隐含预期的差值」而非绝对增速高低；高估值一致预期下的“符合预期”大概率见光死，而低预期低拥挤下的边际拐点（毛利率回升、订单超预期）才具备最高赔率。
- 逻辑链条：财报前股价已计入卖方一致预期 → 利好落地若无上修新叙事即发生估值消化。
- 适用条件：中报、年报、季报密集披露窗口期。
- 失效信号：长周期供需缺口持续扩大导致的连续多季度业绩上修。
- 可信度：0.84（核心基本面卡）
- 来源：二级市场基本面研究通用原则

<a id="method-010"></a>
## 卡片 010 | 行为金融（FOMO 追高、处置效应与违纪成本量化）

- 核心论断：人类交易者最致命的两大行为偏差是「怕踏空（FOMO）追买乖离极值」和「处置效应（急于止盈赚钱的好票、却死扛跌破止损的烂票）」；必须对每笔交易打上行为标签并货币化核算「违纪坏习惯亏钱成本（Mistake Cost）」。
- 逻辑链条：将抽象心理弱点转化为账本上刺眼的亏损金额 → 强制建立盘前检查清单与硬止损纪律。
- 适用条件：所有主观交易者日常复盘。
- 失效信号：无失效（长期适用）。
- 可信度：0.90（核心防错卡）
- 来源：行为金融学公开理论（参考 Edgewonk 复盘理念）

<a id="method-011"></a>
## 卡片 011 | 组合风控（同方向多标签集中度红线）

- 核心论断：看似分散持有 4 只不同代码，但若底层都映射「同一算力/主题因子」，极端退潮日会同步暴跌；必须按全题材标签计算「同方向最大暴露比例」（建议单股 ≤25%、同主题 ≤45%）。
- 逻辑链条：识别底层共同贝塔暴露 → 避免伪分散导致的组合净值剧烈回撤。
- 适用条件：多只标的组合持仓管理。
- 失效信号：牛市主升极强单边阶段可能略微降低弹性，但大幅提升长期夏普比率。
- 可信度：0.85（核心组合卡）
- 来源：机构组合风险管理通用原则

<a id="method-012"></a>
## 卡片 012 | 监管红线（严重异动与重点监控高度天花板）

- 核心论断：A 股高标触发交易所 10 日 4 次异动或被列入重点监控名单时，资金接力风偏会骤降并形成隐性高度天花板，应将其纳入本地监管红线名单，严禁在监控窗口内重仓追高接力。
- 逻辑链条：监管异动触发大资金风控合规限制 → 高位流动性瞬间退潮 → 易现连续核按钮回撤。
- 适用条件：A 股高位连板及短期暴涨题材股。
- 失效信号：低位大市值趋势白马通常不涉及短线异动监管。
- 可信度：0.86（核心风控卡）
- 来源：A 股交易制度公开规则

# 冲突解决矩阵

<a id="conflict-1"></a>
## 冲突 1（v1.0）：情绪冰点左侧低吸 vs 趋势右侧突破确认

- 双方：卡片 007 与卡片 001
- 冲突点：情绪冰点往往出现在趋势尚未完全企稳的左侧，而维克多 1-2-3 要求右侧突破下降趋势线确认。
- 折中思路：实行双线分治与分批建仓——冰点期仅用试错小仓（≤总资金 10%）锚定核心先手，待放量突破下降趋势线或站稳 POC 筹码峰后再补足主仓。

<a id="conflict-2"></a>
## 冲突 2（v1.0）：海外龙头大涨映射 vs MA5 正乖离禁追红线

- 双方：卡片 008 与卡片 006
- 冲突点：隔夜美股龙头暴涨往往刺激 A 股对应核心股高开并瞬间突破 MA5 +8% 乖离红线。
- 折中思路：以卡片 006 赔率底线优先——高开过猛直接跳过竞价追高，观察早盘 30 分钟回踩分时均价线（VWAP）承接力度，不回踩则宁可放过并记入「否决观察池」事后对照检验。
