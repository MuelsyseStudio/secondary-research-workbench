# 离线脱敏演示数据包（Demo Market Packet）

本目录包含一套完全脱敏、合成构造的模拟历史交易日数据包（`demo-daily-packet.json`），用于让商业版新用户在**零外网、零 API Key、零自配数据源**的前提下，直接完整体验以下工作流：

1. 每日复盘 Step 0 数据底座渲染（指数分时图谱、涨跌停三池、≥3 只行业集群、连板梯队与观察股分时）
2. Step 1 结构化证据登记与防未来函数离线核验
3. Step 2 独立可分享 HTML 复盘研报预览与导出（含页脚合规免责声明）

> **免责声明**：本数据包全部标的与数值均为脱敏构造样本，不对应任何真实证券或历史交易事实，不构成任何投资建议。
